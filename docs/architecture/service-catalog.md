# Service Catalog

| Service | Owns | Does not own |
|---|---|---|
| Identity/Tenant | users, invitations, memberships, roles | project documents |
| Engagement | projects, milestones, meetings, decisions | document binary/versioning |
| Documents | metadata, versions, publication, blob refs | approval decisions |
| Approvals | requests, decisions, approval state | email delivery |
| Commercial Read | invoice/hour/retainer projections | accounting source of truth |
| Notification | templates, delivery attempts | approval truth |
| Audit | immutable business/security audit | domain state |
