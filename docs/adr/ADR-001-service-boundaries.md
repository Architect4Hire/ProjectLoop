# Service Boundaries

- **Status:** Accepted
- **Date:** 2026-08-16

## Context
Project Loop requires an explicit durable architecture decision for this concern.

## Decision
Start with Identity/Tenant, Engagement, Documents, Approvals, Commercial Read Model, Notification and Audit as proposed bounded services. Confirm adjustments through ADRs rather than feature scaffolding.

## Consequences
- Implementation and review rules must follow this decision.
- Deviations require a new/superseding ADR.
