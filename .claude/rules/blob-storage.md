# Blob Storage Rule

Blob Storage owns binaries only. Use opaque object keys, private containers, app-mediated authorization, short-lived access where used, hashing, validation and quarantine/scanning workflow.

## Required checks
- Follow the root `CLAUDE.md`.
- Preserve service ownership.
- Add or update tests for changed behavior.
- If a change establishes a new architectural convention, create/update an ADR first.
